# Brendon Baugh — Systems Operator

Independent builder shipping the automation stack I actually run every day: operator consoles, CLI tooling, and dashboards that keep my companies, channels, and habits moving.

## What I build
- **Command surfaces for my own workflows** — Rust + TUI shells, zsh tooling, and infrastructure that sit on top of Google Workspace and OpenClaw.
- **Streaming + creator automation** — bots, dashboards, and schedulers that let me clip, publish, or analyze content without waiting on SaaS.
- **Personal operating systems** — mood tracking, daily call cadences, and discipline tools that keep me accountable.

## Active builds
- **[gogui](https://github.com/br1ghts/gogui)** · Rust terminal cockpit for Google Tasks, Gmail, and Calendar with a unified command palette, module views, and offline token cache.
- **[ytcli](https://github.com/br1ghts/ytcli)** · Scriptable YouTube analytics CLI (Node + TypeScript) that hits the Data & Analytics APIs for channel, video, and metric exports.
- **[zap](https://github.com/br1ghts/zap)** · Twitch clip automation stack: Fastify dashboard, tmijs worker, and shared clip service for connected channels.
- **[moods](https://github.com/br1ghts/moods)** · Laravel 12 + Inertia + React tracker that logs feeling, prompts reflection, and surfaces trends via PostgreSQL.
- **[project100](https://github.com/br1ghts/project100)** · Lightweight Python call ticker I use to keep daily outreach honest.
- **[brendonbaughcom](https://github.com/br1ghts/brendonbaughcom)** · PHP/GPL site powering my public homepage with custom components instead of a bloated theme.

## Stack on rotation
- **Rust** for terminal apps (eg. gogui).
- **TypeScript / Node** for CLIs, bots, and schedulers (ytcli, zap).
- **Python** for quick ops utilities (project100).
- **Laravel / PHP** for heavier internal tools (moods, brendonbaughcom).
- **Shell + OpenClaw** for automation glue, provisioning, and agent ops (Jackson, dotfiles).

## Currently experimenting with
- Scaling `Jackson` (private) — my OpenClaw-based operator that runs the gateway, heartbeats, and assistant flows I need.
- Hardening Rust TUIs against OAuth edge cases while keeping startup under 50ms.
- Turning the clip + analytics stack into reusable modules other creators can self-host.
